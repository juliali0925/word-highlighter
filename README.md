# 单词高亮扩展 (Highlight Words Extension)

这是一个Chrome浏览器扩展，用于在网页上高亮显示指定的单词，帮助用户学习英语词汇。

## 主要功能

### 1. 单词高亮
- 自动高亮显示预设的单词列表
- 支持用户自定义单词
- 区分已掌握和未掌握的单词
- 智能句子提取，显示包含单词的完整句子

### 2. 统计功能
- 统计每个单词在页面上的出现次数
- 记录最近出现的句子
- 支持分页显示，每页可显示25/50/100个单词
- 自动获取单词释义（在线API + 本地缓存）

### 3. 单词管理
- 标记单词为已掌握/未掌握
- 导出已掌握单词列表
- 清空统计数据
- 右键菜单快速添加单词

## 最近改进

### 句子显示优化
- **解决句子被折叠的问题**：句子列现在支持换行显示，不再被截断
- **自适应行高**：表格行高根据内容自动调整
- **更好的句子提取**：优化句子提取算法，获取更完整的上下文

### 释义系统优化
- **多API源支持**：使用多个释义API源，提高成功率
- **本地释义缓存**：words.json文件包含常用单词的释义
- **智能缓存机制**：避免重复API调用，提高性能
- **更好的错误处理**：减少"暂无释义"的情况

### 用户体验改进
- **响应式设计**：支持不同屏幕尺寸
- **平滑动画**：添加淡入淡出效果
- **更好的视觉反馈**：悬停效果和状态指示

## 使用方法

1. **安装扩展**：将扩展文件加载到Chrome浏览器
2. **浏览网页**：扩展会自动高亮显示预设单词
3. **查看统计**：点击扩展图标查看单词统计信息
4. **管理单词**：在统计页面标记单词为已掌握
5. **添加单词**：右键点击单词快速添加到生词本

## 技术特点

- 使用Chrome Extension Manifest V3
- 支持异步API调用和本地存储
- 智能文本处理和正则表达式匹配
- 响应式CSS设计和现代UI组件

## 文件结构

- `manifest.json` - 扩展配置文件
- `content.js` - 内容脚本，负责页面高亮
- `background.js` - 后台脚本，处理右键菜单
- `stats.js` - 统计页面逻辑
- `mastered.js` - 已掌握单词页面逻辑
- `words.json` - 默认单词列表和释义
- `styles.css` - 高亮样式定义

## 注意事项

- 释义API可能有请求限制，建议合理使用
- 句子提取基于标点符号，某些特殊格式可能影响效果
- 扩展需要访问网页内容权限才能正常工作
